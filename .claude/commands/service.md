## Workflow

1. Locate the feature.
2. Locate the component.
3. Locate its template.
4. Search for one similar component if necessary.
5. Inspect directly related services/models.
6. Implement the smallest change.
7. Run targeted tests.

## Rules

- Follow the project's Angular version.
- Follow existing standalone/module conventions.
- Reuse existing UI components.
- Reuse existing services.
- Avoid business logic in components.
- Do not introduce new state management unnecessarily.
- Do not refactor unrelated templates.

Only modify files required by the task.
